## Чек-лист юного видеомейкера
1. Идея и концепция
   -  Идея

   -  Оценка бюджета
   -  Сценарий
   -  Концепт-арт или референсы

2. Препродакшн
   -  Сценарий доработка
   -  Раскадровки
   -  Кастинг актеров
   -  Подбор локаций и декораций
   -  Утверждение бюджета и графика

3. Продакшн
   - Съемочный процесс
   - Операторская работа
   - Звукозапись
   - Грим, костюмы
   - Освещение и техническое обеспечение

4. Постпродакшн
   -  Монтаж видео
   -  Звуковое оформление
   -  Визуальные эффекты (если требуются)
   -  Цветокоррекция
   -  Финальная версия
